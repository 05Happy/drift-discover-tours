# Drift & Discover website

## Open it on your computer

Double-click `index.html`. It will open in your web browser. You need an internet connection for the travel photographs and Google fonts to load.

## Change the photos

The current site uses high-quality placeholder photography. Before launch, replace the three `images.unsplash.com` links in `styles.css` with the business's own approved photos. This is especially important for a travel company: real guest and destination photography builds trust.

## Update the details

Open `index.html` in any code editor (Visual Studio Code is free). Search for the text you want to change, such as `23,000`, a phone number, or a tour day. The WhatsApp enquiry link currently goes to +91 87778 68672.

## Launch it free with Netlify

1. Go to https://www.netlify.com and create a free account.
2. On the dashboard, choose **Add new site** and then **Deploy manually**.
3. Drag the entire `drift-discover-tours` folder onto the upload area.
4. Netlify gives you a live website link immediately. Test it on your phone and send it to the client.
5. When they buy a domain such as `driftanddiscover.in`, open the site's **Domain management** in Netlify and follow **Add a domain**. Your domain seller will show where to update the DNS records.

## Important before sharing

Confirm the agency's final pricing, hotel names, photographs, and whether GST is included. The site presents only the supplied Standard Package information; terms are summarized rather than fully reproduced.
